使用说明

基本操作

  • 点击时间轴按钮切换不同时期
  • 点击关系图中的人物节点查看其关系网络（切换中心人物）
  • 使用鼠标滚轮缩放，拖拽查看不同区域
  • 移动端支持双指缩放和单指拖拽

关系筛选

  • 范围筛选: 全部 / 同班 / 跨班 三种模式
  • 类型筛选: 可单独勾选朋友、暗恋、恋人、舍友、同学
  • 搜索栏: 输入名字后按回车或点击🔍，搜索当前时期的同学并切换为中心人物
  • 筛选器变化时关系图会实时刷新

跨班人物说明

  • 图中带橙色虚线边框 + ⟂ 标记的为跨班人物
  • 跨班人物指不在当前时期 roster 中、但通过特殊关系出现的其他时期同学
  • 悬停跨班人物节点可查看其出现的所有时期

Owner 模式

  • 点击右上角"Owner 登录"输入密码进入编辑模式
  • Owner 模式下可添加人物、添加/修改/删除关系
  • 支持导出 data.json 和导入 JSON 文件
  • 数据持久化流程: 编辑 → 导出 data.json → 提交到 GitHub → 部署生效
  • 退出登录可返回 Visitor 模式（仅查看）
